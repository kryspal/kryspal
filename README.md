# Kryspal Media

A fast, self-hosted media server for your own library. Run it with Docker on a NAS or any small machine, point it at your movies and shows, and watch on the devices you already have.

## What it is good at

- **Fast on big libraries.** Browsing and filtering up to 30× faster than traditional media servers.
- **Original quality.** Your files play as they are, so a small machine is enough.
- **Works with the players you already use.** Third-party players built for Emby or Jellyfin connect to it, next to Kryspal Media's own web player.
- **Free to start.** The FREE edition is a complete media server. PRO and MAX add more members, devices and smart features.
